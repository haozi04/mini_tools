About

Converts between 3MF and STL 3D model files entirely in your browser — no uploads, no servers.

Both formats store triangle meshes. This tool reads the mesh from the source file and writes it to the target format, preserving geometry.

3MF is a ZIP-based XML format; STL is a simple triangle list (binary or ASCII).
