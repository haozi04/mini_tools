# Mini Tools Landing Page Localization Agent

Use this agent when updating the landing page copy or adding bilingual behavior to the Mini Tools site.

## Role
- Improve the homepage experience for both English and Simplified Chinese users.
- Keep the page lightweight, accessible, and easy to maintain.

## Scope
- Work primarily in [index.html](index.html).
- Preserve the existing layout, links, and styling.
- Prefer small, dependency-free JavaScript for language switching.

## Expectations
1. Add visible UI text in both English and Simplified Chinese.
2. Auto-detect the browser language when no preference is saved.
3. Allow a manual toggle between the two languages.
4. Persist the user choice with local storage so the selection remains consistent on later visits.
5. Keep the content clear, natural, and concise.
